# Задание 7. Проектирование схем коллекций для шардирования данных

### Схема Коллекция Заказы
- название - Order
  - схема
    - [order.plantuml](schemas/order.plantuml)
- потенциальные кандидаты для шард-ключей
  - user_id, geo_zone, date_order

- выбираем стратегию
  - горизонтальная по user_id
    - так как по заданию есть основные операции: 
      - Поиск истории заказов конкретного пользователя
- пример инициализации шардирования коллекции
```
sh.enableSharding('somedb');
sh.shardCollection('somedb.order', { 'user_id': 'hashed' });
```

### Схема Колекция Продукты
- название Product
  - схема
    - [product.plantuml](schemas/product.plantuml)
- - потенциальные кандидаты для шард-ключей
  - category, geo_zone, price
- стратегия
  - горизонтально по category и price
    - так как по условию Поиск товаров по категориям и диапазону цен
      - а Частые обновления остатков при покупках уже делать по шарде Категории и цены
- пример инициализации шардирования коллекции
```
sh.enableSharding('somedb');
sh.shardCollection('somedb.product',  { category: 'hashed', price: 'hashed' });
```


### Схема Коллекция Корзина закаказов
- название - Cart
- схема
  - [cart.plantuml](schemas/cart.plantuml)
- потенциальные кандидаты для шард-ключей
  - user_id, session_id

- выбираем стратегию
  - горизонтальная по user_id
    - так как по заданию есть основные операции:
      - Слияние гостевой корзины в пользовательскую, если пользователь залогинится
- пример инициализации шардирования коллекции
```
sh.enableSharding('somedb');
sh.shardCollection('somedb.cart', { 'user_id': 'hashed' });
```
