# Задание 9. Настройка чтения с реплик и консистентность

## Задача
- определить для Коллекций Продукты, Заказы и Корзина
  - операции чтения с какоой реплики
  - указать допустимую задержку для Secondary


- Product
  - Частые обновления остатков при покупках.
  - Поиск товаров по категориям и фильтрация по диапазону цен.
  - Описание товара на странице продукта.

- order
  - Быстрое создание заказов с одновременным списанием остатков.
  - Поиск истории заказов конкретного пользователя.
  - Отображение статуса заказа.


- cart
  - Создание корзины, когда заходит гость или новый пользователь.
  - Получение текущей корзины по фильтру { session_id, status:"active" } или { user_id, status:"active" }.
  - Добавление или замена товара в корзине.
  - Удаление товара из корзины.
  - Слияние гостевой корзины в пользовательскую, если пользователь залогинится...
  - Отметка корзины как заказанной.

| Оперция                                                     | Коллекция | Primary/Secondary | Комментарий                                                                                                            |
|-------------------------------------------------------------|-----------|-------------------|------------------------------------------------------------------------------------------------------------------------|
| Поиск товаров                                               | product   | Secondary         | Нагружаем реплики, ибо распределяем траффик, новые товары не так часто вносятся в систему, в основном будут актуальные |
| Описание товара                                             | product   | Secondary         | Вносятся не так часто, распределяем траффик чтения на реплики                                                          |
| Частые обновления остатков при покупках                     | product   | Primary           | Данные должны быть актуальны, так как необходимо показывать актуальное количетсво товара                               |
| Поиск истории заказов                                       | order     | Secondary         | Заказы обновляются (создаются) не так часто, задержка не так важна                                                     |
| Отображение статуса заказа                                  | order     | Primary           | Реальные "онлайн" данные для пользователя                                                                              |
| Быстрое создание заказов с одновременным списанием остатков | order     | Primary           | Данные должны обновлять в реальном времени                                                                             |
| Создание корзины                                            | cart      | Primary           | Корзина должна сразу создаваться и видна пользователю                                                                  |
| Получение текущей корзины по фильтру                        | cart      | Primary           | Реальные "онлайн" данные из корзины пользователя                                                                       |
| Добавление, замена или Удаление товара в корзине            | cart      | Primary           | Внесение должно быть актуальным                                                                                        |
| Слияние гостевой корзины                                    | cart      | Primary           | Реальные "онлайн" данные из корзины пользователя                                                                       |
| Отметка                                                     | cart      | Primary           | Статус корзины должен быть актуальной для дальнейшего действия с корзиной в системе                                    |

## Задержки для Secondary
- product - каталог, описание - допустима большая задержка 1-5 секунд (нечастые операции изменения данных)
- order - поиск - 1-5 секунд, допустима небольшая задержка
- cart - получается чтение с Primary
